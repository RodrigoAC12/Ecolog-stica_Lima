## Versionamiento

Sprint 3 corresponde a la versión **1.3.0** del proyecto. Se sincronizan README, notas de versión, frontend, package-lock, versión OpenAPI del backend y configuración del análisis Sonar. Los identificadores V_1_0_x de los informes son versiones documentales y se mantienen independientes.

Las referencias a 1.2.4 en antecedentes y los identificadores `1.2.4-sprint3-*` en evidencias Sonar describen sus cortes históricos. Las revisiones internas del README durante la preparación quedan consolidadas en la versión 1.3.0.

## Alcance del Sprint 3

- Cinco informes oficiales: revisión, retrospectiva, calidad de código, OWASP 2025 y WCAG.
- Corrección de JWT sin expiración, botones de formulario, foco de navegación y superficies para medir contraste.
- Evidencia de 36 pruebas backend, 11 frontend y compilación; cobertura frontend de líneas 92,75 %, cuatro formularios 100 %.
- [Análisis real de SonarCloud](<../03 Implementación/Sprint 03/03 Calidad de código V_1_0_0.md>) de `fd9ede18`: gate aprobado, 81,6 % global, 92,9 % nuevo, duplicación 0 % y cero problemas abiertos.
- Trece estados de interfaz, 16 comprobaciones de interacción y 437 de contraste aprobadas en el alcance documentado.
- Entorno exclusivamente localhost, con HTTP y verificación HTTPS local; secretos fuera de Git.

El análisis Cloud identifica la revisión exacta evaluada. La demostración técnica de las 15 historias existentes se resume en la [Revisión del Sprint](<../03 Implementación/Sprint 03/01 Revisión del Sprint V_1_0_0.md>).
